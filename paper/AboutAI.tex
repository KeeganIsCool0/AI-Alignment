	\begin{abstract}
		Artificial Intelligence has rapidly emerged from generating text, images, videos, and code to becoming increasingly sophisticated; growing into a system that has reasoning and automated task completion. However, these systems have caused concerns about AI surpassing human intelligence and becoming misaligned. These misalignment concerns are true, however, predicting an entire doomsday style scenario turns into fear mongering. Recent tests on AI have revealed that it is misaligned. This paper examines how an AI takeover scenario could be likely or unlikely and how it compares to what researchers have been saying about AI safety. It will distinguish intelligence from agency, autonomy, and physical capability, while examining arguments involving AI alignment, recursive self-improvement, goals, cybersecurity, robotics, and control of critical infrastructure. This paper argues that AI could cause some catastrophic risks, but human extinction is not an inevitable consequence. Although predictions of an AI takeover are heavily researched and are credited by highly regarded researchers in they AI field, they give no reason to why and how AI will take over. These researchers base their thesis on assumptions of AI's ability to improve themselves, acquire resources, and overcome human safeguards. Rather than dismissing these concerns this paper distinguishes certain risks with genera assumptions made by these researchers.
	\end{abstract}

	Between answering a question, making a plan, executing a plan, and pursuing a goal independently, lies in who is controlling it; who is asking the questions. Increasing a models skills makes it smarter, but it does NOT give personal desire, self-awareness, or the ability to act on its own.

	\subsection{Making a plan}

	\subsection{What is an objective function?}
	The objective function takes model parameters or decision variables as inputs and outputs a single numeral score. The training algorithm adjusts the internal parameters to push this score toward its optimal extreme; either the lowest or the highest number.
	The minimization Formula is used when the goal is to reduce error or distance from the truth, such as in linear regression when the Mean Squared Error (MSE) is minimized: 
	$$MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$
	
	\subsection{Reward Hacking}
	Reward Hacking happens when a learning model finds exploits, loopholes and shortcuts in its reward function to get a high score without completing the intended task. Designers set a mathematical reward function to measure success. If the rule is imperfect, the AI optimizes for the rule instead of a designers true intent of the goal. For example an AI might find coding loopholes to learn to modify unit tests and rewrite a timer so it reports a successful result instead of working on the actual code.
	
	\subsubsection{Basic Reward equations}
	The reward function (R) maps a transition, defined by the current state(s), the action taken(a), and the next state(s') to a real number.
	\[ R: S \times A \times S' \rightarrow \mathbb{R} \]
	
	\subsubsection{Immediate Reward Equation}
	\[ R_t = R(s_t, a_t, s_{t+1}) \]
	
	\subsubsection{Total Reward Equation}
	\[ G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1} \]
	
	\subsection{Specification Gaming}
	Specification gaming happens when an AI system satisfies the literal definition of a reward while violating the designers intent.
	
	\subsubsection{Why does this happen?}

	\subsection{Where does AI development stop?}
	If we have infinitely improving software (the AI), While the software itself can find ways to rewrite its own code, it will eventually run into physical reality. While hardware is finite, software cannot be infinite. The AI is simply limited by the laws of physics. The Launder Limit states that erasing, changing, or adding a bit of data always requires a minimum amount of energy. An infinitely improving AI would melt its hardware. The Bremermann's Limit calculates the maximum speed at which any piece of matter can process information. A computer can only process about: $$1.36 \times 10^{50}$$ bits per second per kilogram. Once the software reaches this speed, it cannot go any faster without adding more mass. Eventually, the software will reach "peak optimization" where the code is as perfect as mathematically possible with that specific piece of hardware.

	\section{Compute Limits}
	The main limit of AI is compute. AI requires billions of transistors to talk each other. However, bits can not travel faster than the speed of light. If a computer chip is too large, it takes too long for data to travel from one side to the other, causing a bottleneck. Every time b 0 changes to a 1 it produces a small amount of heat. If you pack too much computation into a single space, it will melt itself from this heat. The Bakenstein Bound storage rule dictates the absolute maximum amount of data that can be stored in a physical volume. This is the formula:
	\[
	S \leq \frac{2\pi RE}{\hbar c}
	\]
